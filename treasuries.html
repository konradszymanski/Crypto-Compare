How to read this

Reported holdings, not a market signal

CoinGecko aggregates reported Bitcoin holdings. Values in USD move with BTC’s market price; holdings may be estimated or reported on different dates. Government holdings may include seized assets and do not necessarily represent a policy reserve. This data does not show intent, future buying, or future returns.

Coverage and limitations

A reported snapshot, not a complete ledger

Public disclosures can lag, holdings can be attributed differently, and reported estimates may change. The listed entities reflect CoinGecko’s tracked coverage at the snapshot date, not every wallet or institution. USD values are calculated from the source’s snapshot and are not a live quote.

CoinGecko’s authenticated API refresh is run by GitHub Actions and proposed as a pull request for review. If that workflow has no configured API key, the checked-in snapshot remains available and the refresh is skipped.
