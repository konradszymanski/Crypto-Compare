Coverage and limits

Read venue data with context

  • Pool activity covers specific on-chain pools and networks; it does not include centralized exchanges or every decentralized venue.
  • Liquidity, volume, transaction counts, and token prices may be missing or delayed. Always follow the source link for pool details.
  • The public GeckoTerminal API is in beta. Its documentation describes cached responses and a low, variable request limit; this page caches results in your browser and does not poll.
  • CoinGecko's derivatives exchange endpoint can report venue open interest and contract details, but it requires a Pro API key. It is deferred until a protected, reviewable snapshot path is available.
